Initial public release

Helm 0.1 provides one native GTK application and first-class CLI for inspecting and safely managing an existing Hyprland desktop on Arch Linux.

Included

  • Hyprland 0.56.2+ Lua settings, displays, keybindings, and named window rules
  • Semantic themes, wallpaper, Alacritty, Yazi, Waybar, and cooperative Quickshell integration
  • Freedesktop startup entries, application defaults, and atomic desired-state profiles
  • Durable transaction history, exact-byte rollback, conflict detection, recovery, and undo
  • Fail-closed Bubblewrap plugin host, framed JSON-RPC protocol, and dual-licensed Rust SDK
  • Native Arch package metadata, dependency policy, fuzz targets, and reproducible release tooling

Compatibility boundary

This release is user-scoped, local-first, English-only, Arch-native, and Hyprland-only. Legacy hyprland.conf is detected but never modified. Follow the official migration guide linked from the integration documentation before using writable Hyprland settings.
